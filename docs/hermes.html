01 · Overview

Kiến Trúc Go-Native Siêu Nhẹ

Bypass hoàn toàn các framework Python cồng kềnh của Hermes gốc. Tích hợp trực tiếp vào nhân Go của Cozyroom, giúp tiết kiệm bộ nhớ & xử lý bất đồng bộ cực nhanh.

🔋 Hiệu Năng Vượt Trội

Thiết kế dành cho homelab cấu hình thấp. Thay vì tiêu tốn hàng GB RAM cho các tiến trình Python nền, Go-native Core chạy mượt mà với chỉ vài MB RAM.

  • Bộ nhớ tĩnh: < 2 MB RAM
  • Khởi động: Tức thì (<10ms)
  • Database: SQLite gọn nhẹ tích hợp sẵn

🛡️ Luồng An Toàn Đa Luồng

Mọi hành động và lệnh tự động đều được quản lý bởi cấu trúc Handler đồng thì (concurrent-safe), chống race condition khi chạy nhiều task nền.

  • Dynamic Tool Registry bảo mật cao
  • Context-based timeout hủy task treo tự động
  • Zero dependencies cồng kềnh phía ngoài

02 · Automation

Bộ Lập Lịch Tự Trị SQLite

Bao gồm cơ chế nạp cấu hình động và lập lịch thông qua biểu thức Cron tiêu chuẩn. Tự động đánh thức Agent thực thi các prompt định sẵn không cần người dùng online.

⏰ Dynamic Reloading (Tải lại động)

Mọi thay đổi từ bộ API (thêm/sửa/xóa lịch hẹn) ngay lập tức kích hoạt hàm callback an toàn và tải lại bộ nhớ lập lịch mà không cần reboot phần cứng.

  • Reload tức thì thông qua callback pointer
  • Tránh import vòng tròn (circular imports)
  • Lấy danh sách dễ dàng bằng tool tích hợp

📦 SQLite Schema Tiêu Chuẩn

Bảng nhiệm vụ lưu trữ các trường dữ liệu thiết yếu, tương thích hoàn toàn với ORM/Native SQL của Cozyroom backend.

CREATE TABLE IF NOT EXISTS scheduled_tasks (
    id TEXT PRIMARY KEY,
    cron_expression TEXT NOT NULL,
    prompt TEXT NOT NULL,
    created_at DATETIME NOT NULL,
    last_run_at DATETIME
);
Các API & MCP Tool hỗ trợ Bộ lập lịch:
Tên Tool / API Chức Năng Tham Số Truyền
schedule_agent_task Đăng ký lịch trình mới vào DB và nạp lại scheduler. cron_expression, prompt
get_scheduled_tasks Lấy toàn bộ danh sách các task đang được lên lịch. Không có
delete_scheduled_task Xóa một task khỏi DB bằng ID và nạp lại scheduler. id
03 · Self-Improvement

Công Cụ Tự Nâng Cấp Kỹ Năng

Cung cấp khả năng tự trị cho Agent. Khi Agent nhận thấy một luồng công việc lặp đi lặp lại hoặc được yêu cầu, nó sẽ tự viết mã, đóng gói tài liệu, và đăng ký Skill mới vào thư viện.

✍️ Cập Nhật Bảng Mục Lục Tự Động

Không chỉ ghi file tài liệu, công cụ phân tích cấu trúc của file `llmwiki/skills/README.md` để tìm đúng bảng thuộc nhóm category và chèn thêm hàng dữ liệu chi tiết một cách chính xác.

  • Tìm kiếm tiêu đề category động
  • Tính toán định dạng Markdown table tự động
  • Tránh ghi đè gây mất mát dữ liệu cũ

🔗 Liên Kết Manifest Đồng Bộ

Mỗi skill mới tạo đều được cập nhật vào cấu trúc JSON để các agent khác trong hệ thống có thể nhận biết và sử dụng ngay lập tức.

  • Tệp Manifest: .template-manifest.json
  • Khóa lưu trữ: Danh sách các skill của Cozyroom
  • Tính năng: Đồng bộ hóa trạng thái tức thì

04 · Connectivity

Bộ Cổng Kết Nối Chat Bot Bảo Mật

Hỗ trợ truy xuất từ xa cực kỳ an toàn. Điều khiển ngôi nhà hay Cozyroom thông qua Telegram và Discord với danh sách trắng (Whitelist) bảo vệ nghiêm ngặt.

💬 Độ Trễ Phản Hồi Thấp (Typing Indicator)

Tự động gửi trạng thái "đang nhập..." (typing status) liên tục trong lúc AI xử lý câu hỏi. Mang lại trải nghiệm mượt mà, phản hồi tự nhiên cho người dùng chat bot.

  • Telegram: Sử dụng API SendChatAction("typing") liên tục
  • Discord: Sử dụng API ChannelTyping() tương thích
  • Phản hồi streaming nhanh chóng

🔑 Cấu Hình Biến Môi Trường (.env)

Dễ dàng tắt/bật linh hoạt mà không lỗi khởi động bằng cách điền đầy đủ hoặc bỏ trống các cấu hình dưới đây:

# Telegram Config
TELEGRAM_BOT_TOKEN="your-bot-token"
TELEGRAM_ALLOWED_USER_ID="your-chat-id"

# Discord Config
DISCORD_BOT_TOKEN="your-discord-token"
DISCORD_ALLOWED_USER_ID="your-user-id"
