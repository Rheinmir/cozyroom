System Design

Homelab music server: React + Go + Citus Postgres + K3s + Cloudflare Tunnel. Clean Architecture. Service Worker multi-layer cache. ~2655 tracks, YouTube integration, MCP AI chat.

01 · Kiến trúc tổng thể

Request path end-to-end

Mọi request từ browser đi qua CF Tunnel → K3s nginx → Go backend → Citus Postgres. Service Worker intercept trước khi ra mạng với StaleWhileRevalidate/CacheFirst.

Ingress
  • Cloudflare Tunnel (CF Tunnel)
  • nginx K3s pod (frontend)
  • SSL termination tại CF edge
Compute
  • K3s (Kubernetes lightweight)
  • Backend Deployment ×3 pods
  • Frontend Deployment ×3 pods
Storage
  • Citus 12.1 · 3 physical nodes
  • Music files hostPath /mnt/f/
  • Covers: DB blob + disk cache
02 · Backend

Go backend — Clean Architecture

4 layers: handler → usecase → repository → domain. Không có circular dependency. Mỗi domain (music, ebook, comic, youtube, ai) có usecase + repo riêng.

Layers
  • handler HTTP, parse request, call usecase
  • usecase Business logic, orchestrate repos
  • repository DB queries (Citus), file I/O
  • domain Entities, interfaces
Key services
  • 🎵 Music — scan, stream (FLAC/320kbps/lossless-clean)
  • 🎬 Video — ffmpeg HLS transcoding, MPEG-TS
  • ▶ YouTube — yt-dlp search/stream/download + 5min cache
  • 📚 Ebook/Comics — serve static, NSFW tag
  • 🤖 AI/MCP — 23 tools, Claude Haiku, SSE chat
  • 📊 Metrics — Prometheus /metrics, Grafana

03 · Frontend & SW

React + Vite + Service Worker

SPA dùng React Query cho data fetching. Service Worker (Workbox) intercept /api/* với StaleWhileRevalidate hoặc NetworkFirst tùy route.

SW Cache strategies
  • StaleWhileRevalidate
    /api/(artists|albums|stats)
    200 entries, 7-day TTL → instant response ⚡
  • CacheFirst
    /api/covers, /api/artist-images
    Images served from cache
  • NetworkFirst
    /api/(tracks|search)
    4s timeout, 100 entries
React Query config
  • Artists/Albums/Stats: staleTime 5min → không refetch khi navigate back
  • AlbumPage: fetchAlbum({id}) → single-row query, staleTime 5min
  • YT search: 300ms debounce → giảm 10× số API calls
  • Player: trackRef.current sync trước setTrack() để tránh stale ref
