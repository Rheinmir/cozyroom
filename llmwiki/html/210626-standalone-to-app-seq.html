Standalone → App Alignment

Workflow tái sử dụng để align giao diện live app với Cozyroom (standalone).html — 5 bước, có thể invoke lại bất cứ lúc nào.

Vấn đề gốc: Mỗi lần align thủ công đều lặp vòng: scan minified JS → screenshot loading state → miss chip labels/layout → sửa lại nhiều lần. Workflow này chuẩn hóa toàn bộ quy trình.
0

Tổng quan pipeline

5 bước chạy tuần tự. T1 (Extract) là input cho T3 (Diff). T2 (Screenshot) là input cho T3. T4 (Apply) nhận output của T3. T5 (Verify) có thể loop về T4 nếu còn mismatch. Tất cả một agent (Claude main) — không cần dispatch vì các bước phụ thuộc nhau.

1

T1 — Extract

Claude main · sonnet-4-6

Claude đọc Cozyroom (standalone).html (file chứa minified JS), grep các object config như posterMeta, kicker, title, tìm CSS custom property. Output là per-page spec: chip label, page title, layout type (grid / list / chat / chart), placeholder text, màu accent — lưu vào structured markdown để T3 Diff dùng. Bước này read-only, không đụng code.

component có sẵn (indigo)
output mới (emerald)

T2 — Screenshot

Claude main · sonnet-4-6

Playwright headless Chrome navigate tới từng page của live app. Không dùng waitUntil: 'networkidle' — với các page phụ thuộc API chậm (ebooks, videos), cần waitForSelector với element chứa real data (ví dụ: .ebook-card, .video-poster-card). Timeout 15s. Nếu timeout → ghi nhận là "API slow" và chụp ngay state hiện tại. Output: 7 file PNG.

waitForSelector (đợi data thật)
3

T3 — Diff

Claude main · sonnet-4-6

Agent đọc per-page-spec.md (từ T1) và screenshots (từ T2), đọc thêm file TSX tương ứng để so sánh. Với từng page: xác định chính xác dòng nào cần sửa — chip label sai, layout type sai, thiếu element, màu khác. Output là diff-report.md với format: | page | file | line | current | expected |. T4 chỉ đọc file này, không phải re-analyze nữa.

4

T4 — Apply

Claude main · sonnet-4-6

Claude đọc diff-report.md và thực hiện surgical edits — chỉ sửa đúng dòng được liệt kê, không refactor xung quanh. TSX edits có thể xử lý parallel nếu các page độc lập. index.css edits phải serialize (không parallel) để tránh conflict. Sau mỗi page: tsc --noEmit để bắt type error sớm. Không build Docker tại bước này — T5 mới verify.

5

T5 — Verify

Claude main · sonnet-4-6

Sau khi Apply xong, build + deploy frontend (invoke deploy-k8s-frontend skill), đợi rollout, rồi chạy lại T2 để lấy screenshots mới. Agent so sánh screenshots mới vs spec: nếu tất cả pages đạt → commit + ghi wiki. Nếu còn page nào lệch → loop về T4 chỉ với các page đó (không redo toàn bộ). Maximum 3 vòng — nếu vẫn còn lệch → flag manual review.

pass → commit
fail → loop về T4
