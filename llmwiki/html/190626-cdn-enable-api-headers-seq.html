Enable CF Cache cho Library API

7 GET library endpoints chưa có Cache-Control: public → CF không cache JSON → mỗi request đều tunnel về homelab. Fix: thêm header vào handler.go.

01 · Hiện trạng

Đã có cache — nhưng thiếu JSON API

Images và audio đã được CF cache. Library JSON endpoints (artists, albums, tracks, stats, search) chưa có Cache-Control → CF relay, không cache.

Đã có Cache-Control ✅
  • 7d /assets/* — nginx immutable
  • 7d /api/covers/{id} — backend
  • 7d /api/artist-images — backend
  • 1h /stream/{id} lossless — backend
Chưa có Cache-Control ❌
  • miss /api/artists, /api/artists/{id}
  • miss /api/albums, /api/albums/{id}
  • miss /api/tracks
  • miss /api/stats
  • miss /api/search?q=...
02 · TTL Plan

Cache-Control: public cho 7 endpoints

TTL khác nhau theo tần suất thay đổi. Search an toàn vì CF cache theo full URL kể cả ?q=.

EndpointHandlerTTLLý do
/api/artistslistArtists300sLibrary chỉ đổi sau scan
/api/artists/{id}artistDetail300sSame as above
/api/albumslistAlbums300sSame as above
/api/albums/{id}getAlbum300sSame as above
/api/trackslistTracks300sSame as above
/api/statsstats60sCounter thay đổi thường xuyên hơn
/api/search?q=...search30sQuery-specific; CF cache theo full URL
Thực hiện: Thêm w.Header().Set("Cache-Control", "public, max-age=300") vào đầu mỗi handler trong backend/internal/api/handler.go. Không đổi logic, không đổi schema.
03 · Risks & Checklist

Điều cần verify trước khi deploy

CF caching chỉ hoạt động khi zone ở chế độ Proxied (orange cloud) và không có Bypass Cache Page Rule.

Risks
  • ⚠ Scan invalidation: Sau POST /api/scan, cached responses stale tối đa 300s — acceptable với homelab
  • ⚠ CF Proxied: CF zone phải ở chế độ "Proxied" (orange cloud) — cần user verify trên CF dashboard
  • ⚠ Page Rules: Nếu CF zone có "Bypass Cache" Page Rule → headers không có tác dụng — cần user check
Checklist deploy
  • ☐ Verify CF zone: orange cloud (Proxied) cho music.giatbh.io.vn
  • ☐ Check CF Page Rules: không có "Bypass Cache" cho /api/*
  • ☐ Add headers vào handler.go
  • ☐ Build + deploy backend
  • ☐ Check CF Cache Analytics: cache hit rate tăng sau 5 phút
