T1 · textarea centering + multiline state Claude main

Mặc định rows=1 + CSS padding-top để center cursor và placeholder theo chiều dọc. Khi user nhấn Shift+Enter, state multiline=true → rows=3 + padding về top. Ghost text suggestion vẫn hoạt động ở cả 2 mode. Submit → reset về multiline=false.

Xoá div riêng chứa Tools + Analytics (đang chiếm 19px), chuyển 2 link vào cuối ai-controls-row với margin-left: auto để đẩy ra phải. Tiết kiệm 1 hàng giữa page title và messages area.
