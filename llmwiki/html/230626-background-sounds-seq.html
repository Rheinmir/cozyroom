T1 Go Backend — Ambient Sounds Endpoint Claude main

Tạo backend/handler_ambient.go với 2 routes: GET /api/ambient-sounds trả danh sách file có trong backend/sounds/ambient/, và GET /api/ambient-sounds/:name stream file audio với header Accept-Ranges để browser loop liền mạch. Noise types (Balanced/Bright/Dark) không cần file — frontend generate bằng Web Audio API. Nếu file không tồn tại → 404, frontend ẩn option đó.
