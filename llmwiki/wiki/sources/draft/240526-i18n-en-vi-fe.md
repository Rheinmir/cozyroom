## 3. Existing behaviour có thể break

- `TrendingPage.tsx` đã có hardcoded Vietnamese ("Giải quyết", "Công nghệ", "Luồng") — phải extract sang translation key
- Nếu localStorage key conflict với `trending-view-mode` → không conflict (key riêng: `app-language`)
- SSR: không dùng SSR → không vấn đề

## 4. Implementation Plan

### Step 1 — Install

```bash
cd frontend && npm install i18next react-i18next
```

### Step 2 — Init file `src/i18n/i18n.ts`

```ts
import i18n from 'i18next'
import { initReactI18next } from 'react-i18next'
import en from './en.json'
import vi from './vi.json'

i18n.use(initReactI18next).init({
  resources: { en: { translation: en }, vi: { translation: vi } },
  lng: localStorage.getItem('app-language') ?? 'vi',
  fallbackLng: 'en',
  interpolation: { escapeValue: false },
})

export default i18n
```

Mặc định `'vi'` — app dành cho người Việt.

### Step 4 — Language toggle UI

Thêm vào cuối `Sidebar.tsx` (trên nút Disconnect):

```tsx
import { useTranslation } from 'react-i18next'

function LangToggle() {
  const { i18n } = useTranslation()
  const toggle = () => {
    const next = i18n.language === 'vi' ? 'en' : 'vi'
    i18n.changeLanguage(next)
    localStorage.setItem('app-language', next)
  }
  return (
    <button className="lang-toggle" onClick={toggle}>
      {i18n.language === 'vi' ? '🇬🇧 EN' : '🇻🇳 VI'}
    </button>
  )
}
```

CSS: nhỏ gọn, dưới cùng sidebar / trước nút Disconnect.

### Step 5 — Replace strings in each file

Pattern uniform trong mỗi component:
```tsx
const { t } = useTranslation()
// ...
<span>{t('nav.library')}</span>
<button>{t('auth.login')}</button>
```

Thứ tự migrate: Sidebar → MobileNav → Header → SearchPage → TrendingPage → TrendingChartMode → PlayerBar → LyricsView → các page còn lại.

### Step 6 — Import i18n trong main.tsx

```ts

```
