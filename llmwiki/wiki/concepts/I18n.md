# I18n — Bilingual EN/VI

## Setup

- Library: `i18next` + `react-i18next`
- Init: `frontend/src/i18n/i18n.ts` — imported in `main.tsx` before React render
- Default language: **VI** (app targets Vietnamese users)
- Persist: `localStorage('app-language')` — survives reload

## Files

| File | Role |
|------|------|
| `src/i18n/i18n.ts` | i18next init, lng detection from localStorage |
| `src/i18n/en.json` | English strings |
| `src/i18n/vi.json` | Vietnamese strings |

## Translation Namespaces

| Namespace | Keys | Usage |
|-----------|------|-------|
| `nav` | library, home, search, artists, films, ebooks, books, comics, trending | Sidebar + MobileNav |
| `auth` | username, password, login, cancel, disconnect, connect_lastfm, network_error | Sidebar Last.fm form |
| `search` | placeholder, title, hint, searching, results_for, no_results, artists, albums, tracks… | Header + SearchPage |
| `trending` | title, chart_mode, grid_mode, refresh, solved, technology, flow, ai_estimated… | TrendingPage + ChartMode |
| `charts` | 9 section titles + empty states | TrendingChartMode |
| `player` | hint, shuffle titles, smart radio labels, translation toggle | PlayerBar |
| `lyrics` | finding, not_found, retry, save, overwrite, cached, wrong_password… | LyricsView |
| `library` | loading, back, artist, album, tracks_count | ArtistsPage + AlbumPage |
| `install` | description, action | InstallBanner |
| `lang` | switch (shows opposite flag) | Sidebar toggle |

## Language Toggle

In `Sidebar.tsx` — bottom of nav, above Last.fm section:

```tsx
const toggleLang = () => {
  const next = i18n.language === 'vi' ? 'en' : 'vi'
  i18n.changeLanguage(next)
  localStorage.setItem('app-language', next)
}
<button className="lang-toggle" onClick={toggleLang}>{t('lang.switch')}</button>
```

- VI active → shows `🇬🇧 EN`
- EN active → shows `🇻🇳 VI`

## Usage Pattern

```tsx
import { useTranslation } from 'react-i18next'

function MyComponent() {
  const { t } = useTranslation()
  return <span>{t('nav.artists')}</span>
}
```

Interpolation: `t('search.results_for', { q })` → `Results for "{{q}}"` / `Kết quả cho "{{q}}"`.

## Out of Scope

- Backend API strings (AI labels, metadata) — not localized
- URL-based locale routing — localStorage is sufficient
- ComicsPage, EbooksPage, VideosPage — minimal hardcoded strings, future if needed
