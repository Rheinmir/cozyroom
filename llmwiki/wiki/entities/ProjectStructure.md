# ProjectStructure
**Type:** entity
**Tags:** file-structure, repository, layers, packages

Repository layout and layer map for Cozyroom — generated by `orca-onboard` Phase 1 (2026-06-19, 329 nodes analyzed).

## Top-Level Layout

```
cozyroom/
├── backend/            Go binary — HTTP API + all server-side logic
├── frontend/           React SPA — Vite + TypeScript + PWA
├── k8s/               Kubernetes manifests (K3s cluster)
├── observability/      Prometheus + Grafana configs
├── cloak-proxy/        Nginx reverse proxy for YouTube URL cloaking
├── llmwiki/            LLM knowledge wiki + harness validators
├── harness/            Git hook scripts (pre_tool_use.py, commit-msg, install-harness.sh)
├── _archive/           Deprecated SQLite repositories (post-Postgres migration)
├── CLAUDE.md           LLM behavioral rules (DB safety, coding style, invocation rules)
├── README.md           Project overview + API reference
├── docker-compose.yml  Local dev compose (legacy; K3s is production)
└── Dockerfile.*        Backend + frontend build images
```

## Backend Package Structure

```
backend/
├── cmd/server/main.go          ← Composition root; wires all deps
└── internal/
    ├── api/
    │   ├── routes.go           ← ~60 route registrations + middleware
    │   ├── handler.go          ← Core: artists/albums/tracks/covers/stream/stats
    │   ├── youtube.go          ← YT: search/stream/download
    │   ├── ai.go               ← Agentic loop (12 rounds, Claude/OpenRouter)
    │   ├── scan.go             ← POST /api/scan → scanner.Scan()
    │   ├── lyrics.go           ← GET /api/lyrics/:id
    │   ├── video.go            ← Video library + HLS playlist
    │   ├── ebook.go            ← PDF/EPUB serving
    │   ├── comics.go           ← Comics page serving + scraper
    │   ├── playlist.go         ← Playlist CRUD
    │   ├── trending.go         ← GET /api/trending
    │   └── scraper.go          ← Web scraping helpers (chromedp)
    ├── cron/cron.go            ← Daily enrichment + trending + cleanup jobs
    ├── db/db.go                ← pgx/v5 pool + query helpers
    ├── discord/                ← Discord slash command bot
    ├── domain/                 ← Interfaces: ArtistRepo, AlbumRepo, TrackRepo, PlaylistRepo
    ├── enricher/
    │   ├── deezer.go           ← Album art enrichment via Deezer API
    │   ├── tmdb.go             ← Video metadata via TMDb
    │   └── github.go           ← GitHub trending scrape + AI scoring
    ├── hls/                    ← HLS .m3u8 + .ts segment generator (ffmpeg)
    ├── lastfm/                 ← Last.fm now-playing + scrobble
    ├── library/scanner.go      ← Walk + tag read + SHA-256 IDs + cover + upsert
    ├── mcp/registry.go         ← 23 MCP tool definitions (JSON Schema)
    ├── metrics/                ← Prometheus: stream_count, stream_duration, ai_tool_calls
    ├── repository/postgres/    ← SQL implementations of domain interfaces
    ├── teams/                  ← Microsoft Teams webhook bridge
    ├── telegram/               ← Telegram bot (/play, /skip, /np, /lyrics)
    ├── transcode/transcode.go  ← ffmpeg → opus/webm transcoding pipe
    └── usecase/                ← SearchUsecase, PlaylistUsecase, StatsUsecase, TrendingUsecase
```

## Frontend Structure

```
frontend/
├── index.html                  ← PWA root + meta
├── vite.config.ts              ← Vite + VitePWA config (NetworkFirst, sw2.js)
├── package.json                ← React, hls.js, @tanstack/react-query, recharts, i18next...
└── src/
    ├── App.tsx                 ← QueryClientProvider + I18nextProvider + PlayerProvider
    ├── AppRoutes.tsx           ← React Router v6 SPA routes
    ├── PlayerContext.tsx       ← Global player state (gapless, queue, YT, localStorage)
    ├── api.ts                  ← Typed fetch wrappers for all backend routes
    ├── index.css               ← Global styles (purple/glassmorphism theme)
    ├── i18n/                   ← EN/VI translations (react-i18next)
    ├── components/
    │   ├── PlayerBar.tsx       ← Bottom persistent player + YT cover retry
    │   ├── RadialNav.tsx       ← Nightingale rose polar nav
    │   ├── NowPlayingSheet.tsx ← Mobile swipe-up bottom sheet
    │   ├── Equalizer.tsx       ← Animated bars
    │   ├── FavoritePill.tsx    ← Heart toggle with optimistic update
    │   └── CoverImage.tsx      ← Blur-hash placeholder + error handling
    └── pages/
        ├── ArtistsPage.tsx     ← Artist grid (mirror reflection effect)
        ├── AlbumDetailPage.tsx ← Tracklist + album art
        ├── VideoPlayerPage.tsx ← hls.js + fullscreen
        ├── AIAssistantPage.tsx ← Streaming AI chat + tool-call display
        ├── AIStatsPage.tsx     ← Token usage + cost charts (recharts)
        ├── TrendingChartMode.tsx← GitHub trending + Nightingale rose
        ├── PlaylistsPage.tsx   ← Playlist CRUD + drag-reorder
        ├── ComicsReader.tsx    ← Page-by-page comics
        ├── EbookReader.tsx     ← PDF.js reader
        └── SearchPage.tsx      ← Unified search
```
