Một lệnh npx skills add … đưa skill vào ~/.claude/skills/ (hoặc đường Codex), cộng cách cập nhật bằng git pull. Không cần Node/Playwright để dùng.

Consumer · Chat-only

02Sinh biểu đồ / báo cáo

Nói ngôn ngữ đời thường với agent (mục đích + nơi đăng); nó tự dịch sang loại biểu đồ đúng. Mặc định ra biểu đồ; chỉ khi nói rõ "báo cáo/annual/white paper/poster" mới vào report mode (R01–R12). Đây là câu chat, đừng dán vào terminal.

→ Ra: 1 file .html đơn, double-click mở. Lưu ý online/offline: Lupi/Basics là SVG offline; Glance/Circular/Force/R11/R12 cần mạng (CDN + font).

Contributor · Shell

03Kiểm chứng khi sửa tool

Chạy node scripts/validate.mjs (tĩnh, zero-dep) và node scripts/smoke-new-charts.mjs (cần Playwright global) trước khi mở PR. Cả hai: exit 0 = pass, 1 = fail.

→ Ra: pass/fail + danh sách vi phạm theo file:dòng. Không sinh file.

⚠️ Đã kiểm chứng bằng chạy thật: validate.mjs báo sai 722 lỗi trên Windows (721 "màu rõ rệt" + 1 Math.random) vì so path hardcode dấu / trong khi path.relative() trả \. Trên WSL/Linux/macOS cùng repo thì 检查通过 · exit 0. Trên máy này: chạy qua wsl bash -lc "… node scripts/validate.mjs". Chi tiết trong 03.
Thứ tự đề nghị. Chỉ dùng công cụ → 01 (một lần) rồi 02 (mỗi lần cần biểu đồ); bỏ qua 03. Sửa/thêm template → clone → sửa → 03 để verify trước khi PR.
